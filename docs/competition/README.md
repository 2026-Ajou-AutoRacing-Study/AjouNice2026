# 대회 규정과 현장 운영 문서

문서 상태: ROUTER. 정리 기준: 2026-10-15.

현재 주행·센서·네트워크·채점 기준은 사용자가 전달한 **규정집 v1.2**를 따른다.
규정과 실제 구현 상태는 구분한다. 규정 보관만으로 코드·JSON·launch 기본값이
해당 규정에 맞게 변경되거나 검증된 것은 아니다.

## 현재 규정

| 목적 | 문서 |
|---|---|
| 개발·운영 핵심 규정과 제출 전 확인 사항 | [v1.2 현재 요약](COMPETITION_RULES_CURRENT.md) |
| 사용자가 전달한 전체 텍스트 | [2026-10-15 보관 원문](261015_대회_규정_v1.2_원문.md) |
| 수정안 CURRENT: START/END·체크포인트 1–14 좌표·yaw·반경, 구표 HISTORICAL | [대회측 체크포인트 안내 백업](261015_공식_체크포인트_안내_보관.md) |

v1.2 개정일은 2026-09-30, 전달된 페이지 표시일은 2026-10-12다.
원문 파일명의 2026-10-15는 저장소 보관일이며 개정일이 아니다.
원문은 첨부 텍스트를 보존했으며 파일 끝 개행만 추가했다. 그림·외부 링크와
체크포인트 상세 좌표는 첨부에 포함되지 않아 이 파일에서 복원하지 않았다.
체크포인트 상세 안내는 이후 별도로 전달되어 위 백업에 원래 숫자 그대로 보관했다.
‘체크포인트는 음영 밖’은 사용자의 지도 그림 기준 판단이며 대회측 유효 GNSS 보장이
아니다. 이후 재배포 수정안(그림 `image-20261007-064744.png`)을 확인했으며 START+1–14는
Spawn 툴0–14와 좌표·yaw가 일치한다. 구표와의 차이를 프로그램 오류로 본 판단은 철회한다.
2026-10-15 운영측은 **CP14 좌표·spawn 위치는 유지하고 GPS 음영 범위를 조정**하겠다고 답변했다.
[현재 공식 링크](https://morai.atlassian.net/wiki/external/ZDcwYmMyZGQ1ZTMxNDBjOTk3ODczODIxYzBjYzI2Mzc)도
답변에서 확인했다. 음영 조정은 반영 예정이며 새 환경의 스폰·GPS·재출발 검증은 대기 상태다.
기존 zero 관측은 변경 전 로컬 EVIDENCE로 보존한다. 코드의 rule monitor 구15점
설정은 아직 별도 동기화가 필요하며 이번 문서 수정으로 바꾸지 않았다.

## 현장 운영과 공식 문의

- [현장점검 체크리스트](260915_field_inspection_checklist.md): 과거 준비·점검 기록.
- [Heading 기준 문의](morai_heading_reference_clarification.md): 시나리오 yaw와
  ROS heading 정합의 문의 자료. 공식 규정의 heading 단위·변환식을 대신하지 않는다.
- 실행값은 [Localization CURRENT](../localization/COMPETITION_LOCALIZATION_CURRENT_STATE.md),
  [BEVFusion CURRENT](../bevfusion/CURRENT.md), 판단팀의 현재 launch/config를 확인한다.

다음 규정이 전달되면 원문을 별도로 보존하고 현재 요약의 해당 항목을 갱신한다.
규정 사실·팀 구현·검증 결과를 한 문장으로 합치지 않는다.
