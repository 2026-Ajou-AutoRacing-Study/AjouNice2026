  여기의 그림은 구그림(1–15)이다. 구그림 CP14는 툴13(현행13)이며 정상 GNSS,
  구그림 CP15는 툴14(현행14)이며 로컬 장면에서 GPS zero가 반복 관측됐다. 실대회 영역까지 확정하지 않는다.
- 로컬 CP15 ScenarioLoad 실험에서 raw GPS가 0이었던 기록은 해당 개발 장면의
  관측이다. 이를 공식 CP15가 GPS 음영에 있다는 근거로 사용하지 않는다.
  이후 제공된 실제 Spawn 툴로도 같은 좌표의 raw NMEA zero를 재현했다. 원인은 로컬
  음영 volume/경계 판정과 대조 중이며, bridge가 좌표를 0으로 만든 현상은 아니다.
- 대회 체크포인트 복귀 검증은 **유효 GNSS에서 위치 재정합 → 새 경로 확인 → 안전한
  제어 재개**를 우선한다. 무GNSS 순간이동 실험의 명시적 좌표 prior를 대회 필수 입력으로
  일반화하지 않는다.
- 표의 yaw는 공식 안내값이다. MR 실행 시 초기 yaw와 연속 yaw는 기존 계약대로
  `/Competition_topic.heading - 1.347°`를 사용한다. 보관 표의 yaw에 보정을 미리 넣거나,
  이미 보정된 localization yaw에 보정을 다시 적용하지 않는다.
- 이 문서를 저장했다고 코드의 체크포인트 좌표·시나리오·reset 기본값이 바뀌지는 않는다.
