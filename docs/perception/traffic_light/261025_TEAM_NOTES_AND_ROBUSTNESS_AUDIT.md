## 관찰 근거로 활용하되 다시 확인할 부분

- D-2의 두 황색과 R+좌화살표는 반드시 분리 수집·학습한다.
  자연 상태 코드는 A/B `1,4,16`, C `1,4,48`, D-2 `1,4,5,16,33`이다.
  지원되지 않는 램프 bit를 요청해 성공한 것처럼 라벨링하지 않는다.
- 정지선 근접 시 신호등이 위쪽 화각 밖으로 나갈 수 있다는 관찰은 중요하다.
  화면 밖의 신호는 더 좋은 CNN으로 복구할 수 없다. 현재 카메라 규정·정차 위치로 재측정한다.
- 거리 표의 B 10.84m/D-2 10.33m와 본문의 D-2 5.6m 등이 서로 다르다.
  과거 맵 v81/v84/v85, 주행 상태, 위치·속도 조건을 새 v87 측정과 섞지 않는다.
- v1.1의 내부 처리 20Hz 표현은 현재 launch의 최대 10Hz와 다르다.
- 6,209프레임·D-2 97.5%는 당시 정책 회귀 기록이다.
  제공 ZIP에는 그 라벨 원본이 없으며 새 CNN·6환경 정확도 인증이 아니다.
- 120초 주기·93초 최대 좌회전 대기는 팀원의 당시 실측 주장이다.
  자연 주기를 새 native 기록으로 확인하기 전 모든 교차로의 고정 타이머로 쓰지 않는다.
- 앞부분 15초 패널티를 이용한 강제 출발 제안은 현재 규정 수치로 재사용하지 않는다.

- 화면 영상은 관찰 자료이며 원본 camera JPEG 또는 동기화된 native GT가 아니다.

## 2026-10-25 예비 시험

모델 source와 가중치는 운영 baseline 그대로 고정했다.
기존 raw bag 두 개에서 JPEG 218장을 원본 bytes/header/record 시각과 함께 추출했다.
그 자료에는 독립 신호 GT·날씨 라벨이 없어 정확도를 계산하지 않았다.

정지 MORAI에서 4개 교차로, 8개 pose-group, 6환경, 채택 JPEG 180장을 확보했다.
환경 API Set 성공·전후 Get과 JPEG 전후 native ID/color를 따로 기록했다.
GT 불일치 4개 retry 원본은 보존하되 채택에서 제외했다.
첫 모델용 split은 train90/val24/test66이며 같은 pose의 환경·phase는 분리하지 않았다.
C의 G 단독처럼 자연 주기에 없는 점등도 분류 분리용 stress로 포함했으므로
이 묶음 전체를 자연 주행 성능으로 해석할 수 없다.

원시 housing 검출과 선택을 별도로 진단한 결과, C20에서 가까운 대상 대신
더 작은 뒤쪽 신호만 잡는 사례를 재현했다. 두 등은 같은 프로그램이며,
아래 정정처럼 자연 주행의 다른 신호 선택 오류가 확인된 것은 아니다.
입력1280은 Sunny의 해당 사례를 회복했으나
Foggy에서는 점등 부분만 낮은 score로 잡히는 예외가 남았다. 운영 imgsz/conf는 바꾸지 않았다.

고정 ImageNet ResNet18 특징에 linear head만 학습한 약지도 예비 결과:

| 근사 지도 ROI / native 상태 기준 | 기존 HSV | 고정 CNN 특징+linear head |
|---|---:|---:|
| val의 전체 램프 조합 일치 | 17/24 | 24/24 |
| test의 전체 램프 조합 일치 | 47/66 | 46/66 |
| test 좌화살표 recall | 3/12 | 6/12 |

**이 점수는 픽셀 GT·실전 정확도·CNN 채택 근거가 아니다.**
후속 독립 시각 QC에서 판독 불명확 24개, 램프 상단 잘림 19개를 발견했다.
합집합 43개를 분석용으로 구분했고, 137개만 해당 근사 ROI의 연구 후보로 남았다.
따라서 예비 결과를 그대로 홍보하거나 기존모델보다 개선됐다고 주장하지 않는다.
원본·첫 split·첫 결과는 수정하지 않고, crop 교정·새 QC·새 검증 시점으로 후속 학습한다.

주요 증거는 `artifacts/evaluation/traffic_light_robustness_261025/`의
`crop_probe_dataset_v1.json`, `frozen_resnet18_linear_probe_v1/metrics.json`,
`visual_qc_by_agent_v1/qc_results.json`이다.

## 후속 기준

CNN 본체 fine-tune에는 완전한 housing crop과 관찰 가능성이 확인된 라벨을 사용한다.
이미 확인한 test는 개발 진단으로 취급하고 새 독립 pose-group을 잠근다.
각 구간의 자연 조합, D-2의 두 황색, 근접·회피 시점·저해상도·판독 불가를 구분한다.
YOLO 미검출/다른 대상 선택, CNN/HSV 분류, 정책 보완, 시간 필터, 실제 정차·출발은
서로 다른 단계로 검증한다. 정책으로 덧붙인 화살표는 분류 정답에 합산하지 않는다.

### C016/C018 해석 정정

팀원의 “가까운 왼쪽 등과 뒤쪽 등은 같은 신호” 설명을 공식 로컬 MGeo와 대조했다.
두 car head는 sync `SSN000009`, `/IntTL3.TL[2]`, 같은 연결 도로를 공유한다.
130초 read-only 조회에서도 두 ID의 성공한 650개 대응 관측은 같은 상태였다.
연속 조회의 시간차가 있으므로 렌더 프레임 단위 완전 동기 인증은 아니다.

앞선 강제 시험은 C016만 바꾸고 C018은 자연 주기에 둬 인위적인 불일치를 만들었다.
이 사진은 C016 crop의 분류 학습·진단에는 쓸 수 있지만, C018을 고른 결과가 자연
주행에서 다른 신호를 잘못 선택했다는 근거는 아니다. 더 작은 동일 신호만 선택되어
화질이 나빠지는 문제와, 다른 프로그램 선택 문제를 구분한다.

C018은 C016보다 약 11m 뒤에 있어 가까운 등이 위로 사라진 뒤에도 보일 수 있다.
그러나 A/B/D-2에 동등한 대체 등이 있다고 일반화하지 않으며, 정적 투영 계산은
지형·차체 pitch·공식 정지선의 실제 통과 검증을 대체하지 않는다.
자연 조회 자료: `natural_cycle_readonly_v1/`. 130초만으로 두 완전한 주기를
확인하지 못했으므로 모든 구간의 주기를 120초로 확정하지 않았다.
