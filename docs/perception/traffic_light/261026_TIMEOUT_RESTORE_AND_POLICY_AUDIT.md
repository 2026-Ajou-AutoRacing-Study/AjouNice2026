# 신호 timeout 복구와 정책 대조

2026-10-26. 당시 소스 검토 기록이며 현재 운영값은 [CURRENT](CURRENT.md)를 따른다.

- 미수신·timeout GO 호환 복구(PR55) 뒤 launch에 남아 있던 0.5초를 사용자 요청으로 기존 1.0초로 복구했다. 하위 YAML은 이미 1.0초였으며 두 진입 launch의 override와 회귀 테스트를 맞췄다.
- 신호가 한 번도 없으면 GO, 받은 신호의 원본 stamp가 1초를 초과하면 GO다. 노드가 정상 발행하는 최신 UNKNOWN·적색은 STOP 판단이다. 미실행과 노드 장애를 구별하는 정책은 아니다.
- 기존 팀원 코드 `b272638a`와 대조했을 때 원본 카메라 stamp 사용, confidence 0.25, 최대 10Hz는 기존에도 있었다. `stop_margin: 0.0`도 유지한다.
- 지도 연결·CNN v5·관측 조합 보존·허가 관측 3회·동일 head의 단발 누락 0.2초 보존은 앞서 검토·승인한 개선이므로 일괄 원복하지 않았다. 과거 7프레임/4표 smoothing과 현재 직접 관측+판단 확인은 다른 구조다.
- 황색 통과와 시간제한 황색 후보는 기본 OFF다. 기존의 무조건 황색 GO로 되돌린 것이 아니다. D의 직진 녹색을 좌회전 허가로 보지도 않는다.
- 1초 timeout GO는 안전성 보증이 아니며, 정상 미실행과 publisher 장애를 구별하지 못한다. 짧은 끊김에서 0.5초보다 일찍 GO로 풀리지 않도록 기존값으로 복구한 것이다.
- GO_OUT은 이동한 Lanelet 정차선 기준이다. 공식 도색선을 아직 넘지 않은 구간의 후속 적색 대응은 별도 검토 대상이다. 사용자 요청으로 지도 정차선을 조정한 것과 새 정책 변경을 구분한다.

검증 범위: launch 기본값 Python 테스트와 문서 검사, source/install 일치 확인. 이 timeout 복구만을 위한 신규 MORAI 실주행은 하지 않는다. 과거 보고서의 0.5초 시험값은 당시 근거로 보존한다.
