## 변경

- 기존 starter 기준 Ego −35~+55m + Ego-relative 객체 배치를 새 5K에서 제거했다.
- 실제 MGeo 횡단보도를 먼저 선택하고, 객체 목표 geometric center를 횡단 축 ±3m에 둔다.
  Ego는 경로를 따라 해당 횡단 위치 이전 또는 통과 직후에 배치한다.
- 접근113장/횡단 관측62장/양보50장/통과 직후25장, 총250장이다.
  각 center 거리 bin은 20–50/8–20/5–10/6–15m이며, 전방90%·통과 후10%다.
- 현재 지도 후보는 CW000000/CW000002다. starter 반경90m·route 거리12m 및
  횡단 축과 Ego 도로 접선의 내적 절댓값≤0.4를 적용했다. 이 수치는 지역 후보 필터이며
  대회 미션 구역 경계를 공식 인증한 값이 아니다. 평행한 CW000001은 제외됐다.
- primary 횡단보도는 family index로 고정하여 재시도가 쉬운 다른 위치로 바꾸지 않는다.
  두 actor는 인접한 실제 횡단보도로 분산한다. 처음 같은 횡단보도에 모았을 때
  250조건 중18개가 이동 corridor/footprint 중첩으로 생성 불가였다.
  분산 후250/250 생성 가능, 평균 재시도0.084회/최대3회다.
- 실제 이동이 필요한 actor는 횡단 축 방향으로 자연 속도 뒤쪽 출발을 한다.
  지형 준비·접지·충돌·ROI·Park 검사를 면제하지 않는다. 정지 외관 자산은 정지 유지다.
- 새 5K config에만 활성화했다. 기존10K config 및 과거 manifest/raw는 보존한다.
  위치·축·중심·Ego arc는 오프라인 감사에서 지도와 다시 대조한다.
