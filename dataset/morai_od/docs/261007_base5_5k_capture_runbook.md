# Sunny13 초기 5K 수집 런북의 이전 경로

문서 상태: REPRODUCTION ROUTER. Sunny13 최종 승인 5K는 이미 완료했다.
현재 데이터와 다음 수집은 [Base5 CURRENT](BASE5_V2_CURRENT.md#capture)를 따른다.
새 다섯 환경은 [fresh 런북](261010_base5_fresh_environment_runbook.md)을 사용한다.
이전 v132/v133의 본수집·중간 보충 명령을 현재 기본 실행 경로로 사용하지 않는다.
원래 source/runtime으로 Sunny13를 재현할 때만 아래 당시 기록을 선택한다.
