# 과거 실행·보고 도구

`fast_lio/`는 과거 FAST-LIO bag 녹화·입력 변환, `reports/`는 과거 중간발표 제작용이다.
`maintenance/`의 날짜별 삭제 실행기는 당시 승인 범위에만 해당한다. 새 삭제 작업에 재사용하지 않는다.
현재 production 실행 절차가 아니다. 원문은 그대로 보관했고 원래 경로·SHA는
[전체 manifest](../../docs/maintenance/context_archive_261024.json)를 따른다.
경로를 고정한 도구는 당시 source commit의 원래 tree에서 별도로 재현한다.
