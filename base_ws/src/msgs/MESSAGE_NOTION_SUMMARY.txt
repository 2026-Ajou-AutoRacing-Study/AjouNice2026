Autoware ROS1 메시지 패키지 분리 정리 - Notion 붙여넣기용

목적
Autoware ROS2 planning 관련 custom 메시지를 ROS1 catkin 패키지로 포팅했다.
이번 버전은 이전 임시 구조처럼 한 패키지에 몰아넣지 않고, 원본 Autoware 패키지명에 맞춰 쪼갠 구조이다.
그래서 ROS 타입 이름이 원본과 거의 동일하게 유지된다.

현재 메시지 패키지 위치
/home/vic/AJOUNICE2026/repo/base_ws/src/msgs

핵심 변경
이전 임시 구조: planning_ros1ver/PathWithLaneId, planning_ros1ver/Tier4Path, planning_ros1ver/RtcCommand
변경: autoware_internal_planning_msgs/PathWithLaneId, tier4_planning_msgs/Path, tier4_rtc_msgs/Command

다른 PC에서 사용 방법
1. base_ws/src/msgs 아래의 메시지 패키지들을 catkin workspace src 아래에 복사한다.
2. catkin_make를 실행한다.
3. source devel/setup.bash를 실행한다.
4. rosmsg show autoware_internal_planning_msgs/PathWithLaneId 로 확인한다.

예시 명령어
cp -r base_ws/src/msgs/* ~/mvp_ws/src/
cd ~/mvp_ws
catkin_make
source devel/setup.bash
rosmsg show autoware_internal_planning_msgs/PathWithLaneId
rosmsg show autoware_planning_msgs/Trajectory

주의
behavior_path_planner는 메시지 패키지가 아니라 BPP Python 코드와 launch를 담는 패키지이다.
메시지는 base_ws/src/msgs 아래의 원본명 패키지들을 사용한다.
