# 미션 예제 위치 변경

공유 미션 예제는 [config/missions](../../missions/README.md)로 옮겼다.

현재 경로는 `config/missions/<미션>/base/example.yaml`이며, 같은 YAML의 공통 목적지·제한시간을 모든 선택 JSON에 적용한다. `.case.yaml`은 더 이상 사용하지 않는다.

개인 YAML과 시나리오는 같은 미션의 `workspace/`에 만든다. 이 디렉터리는 이전 경로 안내만 유지하며 새 예제를 중복 보관하지 않는다.

직접 제작하는 방법은 [시나리오·YAML 제작 가이드](../../../../../../../docs/planning/SCENARIO_VALIDATOR_AUTHOR_GUIDE.md)를 참고한다.
