# Planning Velocity Scenario Atlas

This visualization places independently validated velocity profiles on one long
K-City v44 trajectory so an early stop does not hide later scenarios. The
trajectory follows the connected centerlines of lanelets `201403`, `200184`,
and `200060`. The displayed validation section preserves the original profile
distances without compressing them.

```bash
cd ~/AJOUNICE2026/repo/base_ws
source /opt/ros/noetic/setup.bash
source devel_optimizer/setup.bash
roslaunch bringup planning_velocity_scenario_atlas.launch
```

Color legend:

- Green: no velocity reduction
- Orange: BVP velocity reduction
- Yellow: MVP velocity reduction
- Red: zero-velocity stop

The BVP sections use ROS 2 Planning Simulator reference files for speed bump,
crosswalk, red traffic light, and intersection collision. The MVP sections use
the point profiles generated by `validate_motion_velocity_planner.launch` for a
static object, slow dynamic object, and cruise-following object.

The scenarios are independently validated speed profiles projected onto this
common K-City route for integrated visualization. Their map positions do not
claim that all seven physical map features exist at those exact lane positions.

Generated tables:

```text
~/AJOUNICE2026/local_autoware_planning_sim/results/velocity_scenario_atlas/
  velocity_scenario_atlas.points.csv
  velocity_scenario_atlas.summary.json
```

Published output trajectory:

```text
/validation/planning_velocity_scenario_atlas/trajectory
```

The trajectory contains the same 347 map-aligned points used by the RViz
visualization. `longitudinal_velocity_mps` stores each scenario's validated
output velocity. Because the seven scenarios are independent, `time_from_start`
is calculated from the baseline velocity only to keep it monotonic across the
combined atlas.
