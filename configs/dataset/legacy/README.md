# Base5 보강 프로파일 이력

현재 입력은 [v163](../base5_midrange_reinforcement_v163.json)이다.

- [v161](base5_midrange_reinforcement_v161.json): 최초 후보; 당시 구현 snapshot·중단 근거를 보존한다.

원문 JSON은 수정하지 않았다. 당시 후보를 현재 runtime의 승인 설정으로 재사용하지 않는다.
이동 전후 경로·SHA는 [dataset archive manifest](../../../dataset/morai_od/docs/legacy/MANIFEST.md)에 있다.
