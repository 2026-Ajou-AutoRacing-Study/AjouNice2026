# Historical localization configurations

These are byte-preserved experiment inputs, not production defaults. Current
configuration selection is documented in [../README.md](../README.md).

Old FAST-LIO sensor variants, Sensor4 noise profiles, rejected sigma0.05/Qxy0.05
models and the `.yaml.save` backup were archived after checking current launch,
imports and aliases. Shared bringup-dependent compatibility configs remain in
the parent directory. Reproduction must name a source revision, sensor profile,
heading/time policy and the exact override; never restore this directory as a default.
