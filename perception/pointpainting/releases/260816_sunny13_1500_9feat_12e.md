## Runtime contract

- LRASPP classes: background, pedestrian, vehicle, obstacle
- painted point order: x, y, z, intensity, background, pedestrian, vehicle,
  obstacle, unknown
- PointPillars classes: Pedestrian, Vehicle, Obstacle
- detector range: x/y `[-30, 30]` m
- segmentation resize short side: 384 pixels

## Metric comparison warning

The teammate report is useful evidence that the model learned well, but it is
not yet an apples-to-apples comparison with Fast-BEV. Its reported test GT
counts differ from the Fast-BEV test set and the PointPainting configuration
uses a 30 m square range. Compare detectors only after freezing identical
frame IDs, classes, spatial range and metric implementation.
