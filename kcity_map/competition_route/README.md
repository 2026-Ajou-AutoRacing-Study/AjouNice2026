# 대회 코스 산출물

과거 지도 버전별 산출물은 `competition_route/vXX/`에 보관하고 Drive로 공유한다.
현재 planning route는 실제 launch/config를 우선한다. 과거 v41 reference나 v44 코스를
현재 운영값으로 자동 선택하지 않는다.

범용 생성기: [generate_drive_course_from_map.py](../scripts/kcity_map_workflow/generate_drive_course_from_map.py).
입력 map·reference CSV·출력 디렉터리를 명시하고, 기존 버전은 덮어쓰지 않는다.
지도 준비와 제작 이력은 [지도 README](../README.md)를 따른다.
