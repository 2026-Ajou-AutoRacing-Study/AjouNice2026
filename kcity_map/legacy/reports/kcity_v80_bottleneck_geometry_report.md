# K-City v80 고주로 최종 병목 형상 정리

## 목적

v79의 `105449 → 105599` 경계가 서쪽으로 꺾였다가 `105603` 끝점으로 되돌아오면서 PlanViz와 VMB에서 X자·삼각형 형태로 보였다. `200360 → 201477` 접점은 폭도 약 2.87 m까지 좁아졌다.

v80은 다음 lanelet을 실제 종방향 접점 기준의 단순 사각형 또는 사다리꼴로 정리한다.

```text
200185 → 201453 → 201476
200360          → 201477
```

대상 lanelet은 `200360`, `201453`, `200185`, `201476`, `201477`이다.

## 변경

- `105449`와 `105599`의 접점을 두 경계의 시작·종료점을 잇는 직선 위로 이동했다.
- `105603`은 기존 시작점과 `105599` 종료점을 직접 잇도록 단순화했다.
- `200360 → 201477` 접점 폭을 3.20 m로 보정했다.
- 5개 대상 lanelet의 좌우 경계와 중심선을 실제 시작·끝 접점 2점으로 단순화했다.
- 중심선 접점은 각 좌우 경계의 정확한 중점으로 정렬했다.
- 단순화 후 참조되지 않는 중간 point 179개를 제거했다.
- lanelet ID, way ID, regulatory element, 속도 제한은 유지했다.
