# v75 합류 통로 형상 수정

## 목적과 원인

영역 겹침은 합류 특성으로 허용한다. 문제는 서로 다른 수렴 경로에 공유 경계를 적용하여 200134 끝 폭이 약 0.72 m로 좁아지고, 201446에서 다시 벌어지며 중심선 방향이 약 14도 꺾인 형상이었다. 200130/201441에서도 약 8도 꺾임이 있었다.

GIS A2_LINK와 MGeo의 423/422/445 중심선은 1 cm 이내로 일치한다. MGeo는 같은 A1256W000638로 수렴하는 경로를 정의하고 nominal width 3.5 m를 제공한다. 이를 독립 합류 통로로 변환한다.

## 지도 변경

- 200127 → 201439: A2256W000423 기반.
- 200130 → 201441: A2256W000422 기반.
- 200134 → 201446: A2256W000445 기반.
- 기존 lanelet 1,299개, 속도 태그, regulatory relation 보존. 지도 lanelet 삭제 없음.
- 각 경로의 정확한 상류/하류 접점 node ID 보존. 내부 split도 동일 node를 공유.
- 좌우 경계를 독립적으로 생성하여 겹침을 허용. 이 수렴 구간에는 허위 lateral LC edge를 만들지 않음. 상류 평행 구간의 LC 구조는 보존.
- 우측 통로는 GIS 외곽선 B2256W000025/B2256W001693으로 제한. 기존 진입 접점의 소규모 GIS 좌표 차이는 보존.
- 마지막 10 m에서 공통 출구 200360 방향으로 부드럽게 연결. MGeo 중심선 대비 최대 보정량 약 0.287 m.
- 미사용 가상 중심선 및 원본에 대응하지 않는 옛 경계 way 10개 정리. GIS 물리 표시선은 보존.

## Route 및 런타임

200130 segment는 [200127, 200130, 200134], 201441 segment는 [201439, 201441, 201446]이다. 각 alternative가 route 내부에서 공통 출구 200360까지 이어짐을 graph로 확인했다. 기존 제외 8개와 201438 추가 정책은 유지한다.
Fallback cutoff는 새 중심선의 동일 s=9.142493으로 재투영했다. 좌표 변화는 약 3 cm이다.
실제 설치 Mission Planner와 map loader에서 Route A 45, Route B 55 segments 생성. 선호 ID 순서 유지. 요청 route config SHA와 UUID는 v75로 변경.

소스/설치 공간 런치와 requester를 v75로 전환하고 관련 base 패키지를 두 설치 공간에 빌드했다. 모든 polygon 유효성, 누락 참조, 중복 인접점 및 route 정책 검사 통과. 실제 차량/시뮬레이터 폐루프 주행은 이 검증에 포함되지 않는다.
