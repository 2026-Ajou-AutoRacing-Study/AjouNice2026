# K-City v71 고주로 병합 및 VMB 수정

v71은 v70의 1 m 안쪽 속도 전환 위치와 150 km/h 정책을 유지하면서, 같은 속도와 진행 의미를 가진 고주로 lanelet을 종방향으로 병합한다. 분기·합류·속도 전환·횡방향 topology가 바뀌는 경계는 유지한다.

## VMB 항목

| VMB 항목 | v71 처리 |
| --- | --- |
| 인접 점이 같은 위치: `148210`, `231231` | `231231`을 기존 `148210`으로 통합하고 연속 중복 참조 제거 |
| `148210` 급각점 | 영거리 segment 제거 후 전후 진행각 검증 |
| 교차로 lanelet 점이 polygon 밖 | 7개 `intersection_area`를 외곽으로 0.05 m 확장 |
| TrafficLight 점 순서 | `103861`, `104150`, `103828`을 VMB가 요구한 순서로 반전; `103905` 유지 |
| 100 km/h 초과 | 규정 예외 고주로 32개 lanelet의 150 km/h 정책이므로 의도된 확인 경고로 유지 |

교차로 경고는 lanelet 면적 포함률이 최저 99.977%이고 최대 이탈 거리가 3.72 cm인 수치·경계 오차였다. 5 cm 확장 후 `intersection_area`가 연결된 차량 lanelet 60개의 left/right/centerline 모든 점이 polygon에 포함된다.
